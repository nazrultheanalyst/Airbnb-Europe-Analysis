## 📌 Overview

This project presents an interactive Excel dashboard that analyzes Airbnb data from major European cities. It visualizes guest satisfaction, cleanliness, distance from the city center, pricing, and room type distribution — all in a dynamic and easy-to-understand layout.

## 🎯 Objective

To extract actionable insights from Airbnb Europe listings using Microsoft Excel and demonstrate how Excel can be used as a powerful tool for business data visualization and decision-making.

## 🛠️ Tools & Techniques Used

- Microsoft Excel  
- Pivot Tables  
- Pivot Charts  
- Slicers for interactivity  
- Bar, Doughnut, Pie, Column, Treemap, and Scatter Charts  
- KPI Cards and Conditional Formatting

## 📊 Dashboard Highlights

- **Avg Guest Satisfaction:** 93.10  
- **% Superhost Listings:** 27.9%  
- **Avg Distance to City Center:** 2.68 km  
- **Avg Cleanliness Rating:** 9.44  
- **Room Type Distribution:**  
  - Entire Home/Apt – 68%  
  - Private Room – 31%  
  - Shared Room – 1%  
- **Avg Price by Room Type:**  
  - Entire Home – 290  
  - Private Room – 198  
  - Shared Room – 138  
- **City-wise Satisfaction:** Highest in Amsterdam & Barcelona (95), Vienna (94)  
- **Cleanliness vs Satisfaction:** Positive correlation (R² = 0.4784)

## 📍 Key Insights

- Cleanliness has a strong impact on guest satisfaction  
- Entire homes are most preferred and also costliest  
- Cities like **Rome**, **Paris**, and **Lisbon** have the largest room volumes  
- Interactive slicers allow users to analyze data by Room Type, City, and Day Type

## 📈 What I Learned

- Building advanced dashboards entirely in Excel  
- Creating multi-chart layouts and KPI indicators  
- Using slicers and pivot tables to enable dynamic filtering  
- Applying effective data storytelling with visuals  
- Representing regression and correlation insights with scatter plots


## 🚀 How to Use

1. Open the Excel file  
2. Use the slicers on the left to filter by Room Type, City, and Day  
3. Explore dynamic charts updating automatically based on your selection  
4. Analyze patterns in pricing, satisfaction, and cleanliness
